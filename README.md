# SkillSpace Frontend v2

Vercel-ready JavaScript/Next.js frontend. TypeScript was intentionally removed to avoid Vercel TypeScript build failures. Node 20.x is pinned through package.json engines.

## Deploy
Upload the contents of this folder to the root of your GitHub repository. In Vercel, use the repository root, Framework Preset Next.js, and Build Command `npm run build`.

## Demo admin
Sign in using any email containing `admin`, for example `admin@skillspace.test`, plus any password.

## Included
Login, signup, dashboard, slide-out menu, 9 categories, 10 tasks per category, task detail/submission, earnings, transactions, surveys, withdrawal UI, profile, settings, support and admin task/support controls.
